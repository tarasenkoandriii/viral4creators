Снимок структуры формы

Снимок структуры не читает значения полей. При переносе выбранные значения читаются для локального предпросмотра. Файл остаётся у вас до явного импорта в кабинет.

    

    Перенос подготовленных данных
    

    Только простые HTML-поля. Выберите план из кабинета и проверьте предпросмотр. Пароли, файлы, списки и галочки не заполняются. Отправка остаётся у вас.
    



    

    При заполнении не вызываются обработчики изменения. Формы React/Vue требуют отдельного адаптера; после заполнения проверьте значения. Сайт может самостоятельно обрабатывать введённые данные.
