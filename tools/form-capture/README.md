# Локальный сборщик структуры формы, v0.1.1

Для Chrome/Edge (Manifest V3). Включите режим разработчика в разделе расширений и загрузите распакованную папку. Установка выполняется пользователем; расширение не устанавливается из кабинета автоматически.

Откройте нужную HTTPS-страницу в своей сессии, нажмите расширение, выберите номер формы с нуля, соберите и проверьте снимок, сохраните JSON. В QA → «Стенды» импортируйте его как ожидаемую или текущую структуру. Перед сравнением укажите одинаковый безопасный URL формы: экспорт содержит только origin, без пути/параметров/фрагмента. Путь может содержать персональные идентификаторы, поэтому автоматически не экспортируется.

Разрешения: activeTab и scripting, только после действия пользователя. Нет host permissions, фонового наблюдения, сети, доступа к cookies, localStorage или токенам. Не читает input.value, textarea.value или selectedIndex; имена/id экспортируются только в виде непрозрачных локальных ключей. Это не криптографическое обезличивание и не гарантия анонимности. Структуру и URL перед передачей нужно проверить.

Ограничения: обычные form/input/select/textarea основного документа. Варианты select и подписи не экспортируются (они могут содержать личные данные), скрытые поля пропускаются; нет iframe/Shadow DOM, условных шагов и пользовательских компонентов. Radio и другие неподдержанные типы, поля без стабильного id/name и дубликаты блокируют снимок. Одинаковые снимки не доказывают полного совпадения форм и не разрешают заполнение.

Никаких отправок, принятия условий, заполнения и передачи credentials. Автоматическая отправка снимка в кабинет отсутствует.

Основа разрешений и внедрения функции: [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting). Полный install/popup/download цикл в установленном Chrome/Edge требует отдельной приёмки; проверка функции через DOM сама по себе его не подтверждает.


## Автоматическая приёмка установленного расширения

`cd tools/form-capture/tests && npm ci && npx playwright install chromium && npm test`.

Три E2E загружают расширение в отдельный временный профиль Chromium: реальный chrome.scripting API, UI сборщика, предпросмотр и скачивание JSON; отказ без доступа; очистка прежнего экспорта и понятная ошибка после неудачного повторного сбора. Только синтетические данные и локально перехваченный HTTPS fixture, пользовательский профиль не используется.

Тестовая копия manifest получает разрешение **только** на capture-fixture.invalid и делает popup доступным во fixture iframe; это необходимо для headless UI harness. Поставляемый manifest не изменяется, не содержит host_permissions/web_accessible_resources, что проверяет unit-тест и контроль архива. Этот E2E не подтверждает жест активации activeTab через настоящую кнопку панели Chrome/Edge: ручная приёмка установки и toolbar popup остаётся открытой. Стендовый iframe не является способом использования production-расширения.

Документация подхода: [Playwright Chrome extensions](https://playwright.dev/docs/chrome-extensions).
