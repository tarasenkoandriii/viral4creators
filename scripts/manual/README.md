# Ручные пробы внешних API

Четыре скрипта и две фикстуры (8 МБ) с самого начала проекта: они зовут
**платные** API живьём (Gemini, Laozhang/GPT-5) и нужны только чтобы
руками проверить ключ или формат ответа провайдера. В CI не участвуют, из
тестов не импортируются, документами не считаются.

Перенесены сюда из корня `scripts/` на этапе 53 (В-6.26), чтобы они не
лежали рядом с `check-docs.mjs` и `sync-legal.mjs`, которые CI гоняет на
каждом пуше. Один такой скрипт уже удаляли как мусор
(`doc/VERCEL-READINESS-AUDIT.md`); эти оставлены как справочник по
форматам ответов — удалить можно в любой момент, ничего не сломается.

Запуск: `GEMINI_API_KEY=… node scripts/manual/test-gemini-generate-text.js`
— каждый вызов стоит денег.
