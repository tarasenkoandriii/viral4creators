# Шрифт для OG-карточек

Четыре подмножества Inter (латиница и кириллица, 400 и 700) — 64 КБ
всего. Лежат в репозитории, а не качаются при запуске, чтобы
`scripts/og-tutorial-cards.mjs` собирал ту же картинку и через год, без
сети и без совпадения версий пакета.

**Это НЕ противоречит решению §4.4 ТЗ
`docs-tz/TZ-Enterprise-Tutorial-Landing.md` не подключать webfont.** То
решение — про критический путь живой страницы: там шрифт пришлось бы
качать каждому посетителю. Здесь шрифт запекается в статичную картинку
на этапе сборки, и страница не весит от него ни байта. Зато карточку,
которую человек видит раньше самой страницы, наконец рисует гарнитура
того же класса, что системная (SF Pro / Segoe UI), а не DejaVu Sans,
единственная кириллическая из предустановленных в Linux.

Источник: npm-пакет `@fontsource/inter@5.3.0`, файлы `files/`.
