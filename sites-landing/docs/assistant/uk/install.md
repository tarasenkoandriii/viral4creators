Помічник з'являється на сайті одним тегом `<script async>`. Віджет вантажиться після вашої сторінки, а вікно чату — лише після кліку відвідувача. Ключ сайту і готовий код вставки ви отримуєте в кабінеті помічника в Telegram.

:::claim ownership-verification
## 1. Підтвердіть кожен хост

Віджет відповідає лише на хостах, володіння якими підтверджено: `shop.example.com` і `www.shop.example.com` — це два різні хости. Оберіть один зі способів у кабінеті:

- **DNS:** TXT-запис `%%verifyDnsName%%` зі значенням `%%verifyDnsValue%%`.
- **Файл:** `%%verifyFileUrl%%`, токен — у першому рядку.
- **Мета-тег** на головній сторінці:

```gen:verifyMeta
```

> Хости публічних платформ (`*.myshopify.com`, `*.tilda.ws`, `*.wordpress.com` тощо) підтверджуються лише DNS — тобто віджет працює на вашому власному домені, а не на піддомені платформи.
:::

:::claim install-snippet
## 2. Вставте тег

Вставте код вставки з кабінету перед `</head>` на всіх сторінках. Він виглядає так (ключ — ваш, з кабінету):

```gen:embedTag
```

- `async` обов'язковий: тег не блокує вашу сторінку.
- Другий такий самий тег на сторінці ігнорується.
- Ключ `pk_test_…` працює лише на `localhost` — для налагодження; на сайті потрібен `pk_live_…`.

## 3. Перевірте

Відкрийте сайт: кнопка помічника з'явиться в обраному куті. Запустіть «Перевірку встановлення» в кабінеті — вона знайде тег, перевірить хост і покаже, якої директиви CSP бракує. Якщо кнопки немає — [що перевірити](/%%loc%%/docs/assistant/csp).

## Атрибути тегу

Вигляд і поведінка приходять з опублікованих налаштувань кабінету. Атрибути змінюють їх лише для сторінки з цим тегом — і лише розташування, мову та режим, не бренд.

Table: Атрибути data-* тегу завантажувача
| Атрибут | Значення | Що робить |
| `data-site` | `pk_live_…` | Ключ сайту (обов'язковий) |
| `data-position` | `bottom-right`, `bottom-left`, `top-right`, `top-left` | Кут кнопки |
| `data-offset-x`, `data-offset-y` | 0–200 | Відступ від краю, px |
| `data-mobile` | `fullscreen`, `sheet`, `bubble` | Вигляд чату на телефоні |
| `data-launcher` | `default`, `none` | `none` — без кнопки: чат відкриває ваша кнопка |
| `data-container` | CSS-селектор | Вбудувати чат у блок сторінки |
| `data-lang` | `uk`, `ru`, `en` | Мова інтерфейсу віджета |
| `data-z-index` | число | Шар віджета над сторінкою |
| `data-hide-on` | `/checkout,/cart` | Не показувати на цих шляхах (до 20 масок) |

## Сайти-SPA

Переходи через History API (React Router, Next.js, Vue Router) віджет бачить сам — діалог не обривається. Якщо ваш роутер змінює сторінку інакше, повідомте віджет викликом `%%global%%('route')` — див. [JS API](/%%loc%%/docs/assistant/js-api).
:::

:::claim wp-plugin
## Плагін WordPress

Плагін для WordPress і WooCommerce (ключ у налаштуваннях, «не показувати на сторінках», цілі замовлень, передача покупця) готовий у коді продукту. Його ще не опубліковано — до публікації ставте тег, як описано вище.
:::

:::claim npm-package
## npm-пакет для React, Vue і Next.js

Пакет-обгортка над тим самим завантажувачем (типізований JS API, компонент React, серверний підпис вебхука) готовий у коді продукту, але ще не опублікований у npm. До публікації — тег або `next/script`, як на сторінці React і Next.js.
:::
