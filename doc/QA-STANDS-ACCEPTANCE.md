# Приёмка QA-стендов

Состояние на 14.10.2026. Этот чеклист относится к ограниченной beta; не закрывает все критерии исходного [ТЗ](../docs-tz/TZ-Voice-Generated-Test-Stands.md). Инструкция: [QA-STANDS.md](QA-STANDS.md), доказательства: [отчёт](reports/qa-stands-generative-2026-10-14.md).

## Подтверждено в production

- [x] Базовый стенд создаётся после подтверждения, записи сохраняются после reload.
- [x] Настоящий Soniox распознаёт синтетические RU/UK записи; текст редактируется до генерации.
- [x] Настоящий Gemini создаёт контракт, из которого работают формы и списки двух сущностей.
- [x] Явное название сохраняется, подписи полей выводятся на языке описания.
- [x] Демо-viewer получает отказ создания, editor создаёт запись; сущности разделены.
- [x] При переключении стендов загружается актуальное состояние.
- [x] Изолированные engine-проверки: базовый 7/7, генеративный 6/6; без сброса сохранённых записей.
- [x] Оба вида стендов скачивают валидный OpenAPI 3.0.3 без записей и токенов.
- [x] Vercel assist-api и assist-tma с GET-чтением успешно развёрнуты.

## Подтверждено автоматическими тестами

- [x] Tenant/account/site scope, идемпотентность requestId, конфликт revision, совместимость v1/v2.
- [x] Валидация полей, ссылок экранов, лимитов, типов, enum и сущностей.
- [x] Защита расходов: резерв бюджета до провайдера, учёт billable ошибок, очистка аудио.
- [x] QA viewer допускается только к чтению; demo-admin не расширяет реальные права.
- [x] GET envelope не выполняет mutation-параметры, не записывает данные и не увеличивает revision.
- [x] Клиент использует GET для чтения, защищённый POST для изменения.
- [x] Браузерные fixtures проверяют формы, переходы, дробные значения и освобождение записи.

Эти пункты не означают production-проверку каждого устройства или реальную сессию отдельного QA viewer. Повторный CI #38584502353 прошёл, включая backend и assist; предыдущий #38583600327 завершился ошибкой типов фикстуры.

## Открытые критерии

- [ ] Реальный вход отдельным пользователем QA viewer: чтение/экспорт/проверки разрешены, все операции изменения запрещены.
- [ ] Микрофоны и разрешения Telegram WebView на Android/iOS, разные голоса и шум.
- [ ] Ежедневный браузерный прогон конкретного созданного стенда с отчётом.
- [ ] Аудит вёрстки/доступности/логики с контрольными дефектами и повторной проверкой исправлений.
- [ ] Редактор и история версий контракта, PATCH, связи и вычисления.
- [ ] Replay, latency, экспорт исходников и отдельный preview URL.
- [ ] Единый стенд для Tutorial/AI helper и глобальная админка ресурсов/хранения.

Новые данные для проверки создавайте только в собственном sandbox-аккаунте. Не удаляйте и не сбрасывайте клиентские стенды ради приёмки. Результат теста на mock не переносится автоматически на реальный клиентский сайт.
