# Приёмка работы с тестировщиком

Сквозной прогон того, что построено этапами 154–161
(`docs-tz/TZ-Rabota-s-Testirovshchikom.md`). Каждый этап проверен
аудитом по отдельности; этот документ — про стыки между ними, потому
что именно там дефекты и живут: у каждого из них оба конца выглядят
правильными.

Проходить **в этом порядке** и **живым Telegram-аккаунтом**, а не
dev-обходом: половина проверяемого — про то, чего в dev-обходе нет
(диалог с ботом, `initData`, платформа клиента).

---

## 0. Перед началом

- [ ] В админке есть оператор, и вы под ним.
- [ ] `TELEGRAM_BOT_TOKEN` тот же, что у бота, на котором стоит вебхук.
- [ ] `TELEGRAM_BOT_USERNAME` задан — иначе ссылка приглашения соберётся
      с заметной заглушкой вместо имени.
- [ ] Канал статистики (`TELEGRAM_STATS_CHAT_ID`) подключён: в него
      приходят уведомления о находках. Не задан — находки будут
      приходить молча, и это не сбой, а непрочитанная строка настройки.
- [ ] Второй Telegram-аккаунт под рукой — им и будете тестировщиком.
      Своим собственным нельзя: у оператора обычно уже есть подписка, а
      приглашение поверх платной подписки сознательно отказывает.

## 1. Приглашение

- [ ] `/testing` → «Приглашения»: подпись, две-три галочки сценариев,
      галочка «Вне проекта», потолок `$5`, дата, бриф «Проверьте
      поздравления на iPhone».
- [ ] Создать. Строка появилась, в ней видны сценарии, «вне проекта»,
      `$5/сут` и бриф.
- [ ] «Скопировать ссылку» → в буфере `https://t.me/<бот>?start=t_…`.

**Что проверяется на стыке:** что создание, список и ссылка говорят об
одном и том же приглашении, и что бриф доедет до экрана тестировщика
(шаг 7), а не останется в админке.

## 2. Активация

- [ ] Открыть ссылку со второго аккаунта, нажать START.
- [ ] Бот ответил: доступ открыт, перечислены **ровно те** сценарии,
      что отмечены, упомянуты операции вне проекта, назван срок.
- [ ] Про суточный потолок бот **молчит** — это намеренно: число в
      долларах в первую же минуту ничего не объясняет, а тревожит.
- [ ] В админке: приглашение стало «активировано», в карточке
      пользователя стоят флаг, галочки, срок и потолок.
- [ ] Повторно нажать START по той же ссылке — то же приветствие, без
      второй записи.
- [ ] Открыть ту же ссылку **третьим** аккаунтом — «Эта ссылка уже
      использована».

## 3. Окружение

- [ ] Открыть мини-апп вторым аккаунтом (не просто бота — именно
      приложение).
- [ ] В карточке пользователя в админке появился блок «Окружение
      последнего запуска» с временем.
- [ ] В нём: `surface: TMA`, платформа клиента, семейство ОС, размеры,
      локаль интерфейса, версия сборки.
- [ ] Переключить язык интерфейса, перезапустить мини-апп — `uiLocale` в
      снимке поменялся.

**Стык:** без этого шага следующая находка из бота приедет с
`uiLocale: unknown`, и это правильно — но убедиться надо здесь.

## 4. Находка из бота

- [ ] Написать боту «кнопка генерации не нажимается».
- [ ] Ответ: «Принято, #N».
- [ ] В канал статистики пришло «🔎 Находка #N».
- [ ] В течение двух минут прислать скриншот — ответ «Добавлено к #N»,
      **тот же номер**, новой находки в очереди не появилось.
- [ ] Прислать что-то через пять минут — новая находка с новым номером.
- [ ] Прислать файл больше 20 МБ — находка заводится, и бот отдельно
      говорит про потолок.
- [ ] Прислать стикер — «Не вижу ни текста, ни файла», находки нет.
- [ ] Отправить `/help` — ни ответа, ни находки.

## 5. Разбор

- [ ] `/testing` → «Находки»: обе находки видны, «Открытые» по
      умолчанию.
- [ ] В строке: номер, кто, «бот», начало текста, окружение одной
      строкой, «Висит».
- [ ] Окружение помечено «(последнее известное)» — из бота оно всегда
      такое, и это главное, что должно быть видно.
- [ ] Открыть карточку: полный текст, вложение открывается **по нашей
      ссылке** (не по телеграмовской), окружение раскрывается целиком.
- [ ] Нажать «Отклонено» без причины → отказ с объяснением.
- [ ] Ввести причину → статус сменился, причина видна.
- [ ] Фильтр по ключу окружения показывает соседей по платформе.

## 6. Ответ и возврат мяча

- [ ] В карточке написать ответ, отправить.
- [ ] Тестировщику пришло в личку «По находке #N: …».
- [ ] Статус стал «Ждём ответа».
- [ ] **Ответить на это сообщение** в боте («всё ещё ломается»).
- [ ] Новой находки в очереди НЕ появилось.
- [ ] Статус вернулся в «Чиним» — мяч снова у нас.
- [ ] В канал статистики пришло «💬 Ответ тестировщика по находке #N».
- [ ] В карточке виден весь диалог: наш ответ и его.

**Это главный стык всей работы.** Ответ оператора и ответ на ответ
живут в трёх местах сразу (личка, `botMessageIds`, статус), и разойтись
они могут молча.

## 7. Мини-апп

- [ ] В подвале у тестировщика видны «Сообщить о проблеме» и
      «Тестирование»; у обычного пользователя — нет.
- [ ] Дойти в мастере до шага промпта, нажать «Сообщить о проблеме».
- [ ] Под полем показано, что приложится: сессия и шаг.
- [ ] Отправить с файлом → «Принято, находка №N».
- [ ] В админке у этой находки: источник «приложение», сессия, шаг,
      сценарий, язык ролика, окружение **без** пометки «последнее
      известное».
- [ ] Ссылка на сессию из карточки открывает список сессий с этой
      сессией.
- [ ] Экран «Тестирование» у тестировщика: бриф из шага 1, что открыто,
      срок, «Сегодня потрачено $X из $5», свои находки со статусами.
- [ ] Статусы на его языке: наша «Ждём ответа» читается у него как
      «Ждём вас».

## 8. Границы доступа

- [ ] Открыть `#/testing` обычным аккаунтом → «Тестовый доступ не
      действует», а не «Не удалось загрузить».
- [ ] Отозвать приглашение в админке с причиной.
- [ ] У тестировщика: флаг, галочки, срок и потолок сняты.
- [ ] Написать боту → «Тестовый доступ закончился», один раз, не на
      каждое сообщение.
- [ ] Кнопки в подвале пропали после перезапуска мини-аппа.
- [ ] Прогон платного сценария теперь упирается в обычный потолок.

## 9. Деньги

- [ ] `/testing` → «Прогресс»: расход за сегодня и потолок **рядом с
      именем**. Потолок действует НА КАЖДОГО тестировщика: трое — это
      втрое больше денег в сутки.
- [ ] Сценарий, по которому прогонов ноль, виден строкой с нулями.
- [ ] `/costs`: расход тестовых аккаунтов вынесен отдельно и в общие
      числа не входит.

---

## Чего этот прогон не проверяет

- **Потолок 20 МБ у бота** проверяется только реальным файлом: он
      платформенный, и подделать его локально нечем.
- **Ссылка `getFile` живёт около часа** — что мы скачиваем вложение
      сразу, видно лишь по тому, что оно открывается назавтра.
- **Осиротевшее вложение** при неудачной отправке из мини-аппа
      остаётся в хранилище; уборки для живого владельца нет, см. запись
      в `doc/TODO.md` у этапа 160.
