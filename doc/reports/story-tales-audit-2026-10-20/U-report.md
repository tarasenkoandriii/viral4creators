## Подробно о S2

**ST2-U-01.** `StoryGiftsScreen.tsx:1200-1211` вызывает `api.delete('/story-gifts/:id')` прямо в обработчике. Проба Playwright (`pw_u.py`, `probes.delete`): одно нажатие → `DELETE /story-gifts/g1`, `dialog` = 0. Для READY/APPROVED это необратимое стирание оплаченной озвучки, всех сборок видео и записей вступления. У удаления образа и отзыва согласия `ConfirmDialog` уже есть — здесь нужен такой же.

**ST2-U-02.** `photoPng` (`:102-126`): `scale = min(1, 960/max(w,h))`, всегда `toDataURL('image/png')`, при base64 > 1 398 104 — отказ. Пробы в Chromium: hero 1536×1024 (иллюстрация) принят (1 264 748 симв.); фото-мозаика 1024×768 и hubble 1000×872 — «Слишком большое фото после обработки». Даже PNG с PIL optimize для 960×720 = 1 095 380 Б > 1 МиБ. Сервер (`normalizeStoryPhoto`) принимает до 1024×1024 и 1 МБ и пережимает (принятый hero 948 560 → 790 688 Б). Нужен цикл уменьшения размера.

**ST2-U-03.** `NarratorProfile.tsx:107-114` рендерится в `ManifestScreen` для всех. Проба с 404 от `narrator-looks` (не-владелец): блок образа скрыт, абзац и ссылка `#/stories` видны (`shots/profile-non-owner-light-360.png`). Закрытая разработка раскрыта в публичном интерфейсе, текст по-русски для всех локалей.

**ST2-U-04.** Matcher `middleware.ts:66-71` исключает пути с точкой и добавляет только `/stories-media/:path*`, поэтому `/og/stories-*.jpg` идут мимо middleware. Живая проба (`next dev` копии в `/tmp/sta2-U/landing`, `landing-probe.txt`): `welcome…/og/stories-ru.jpg` → 200 image/jpeg 46 718 Б, `story-tales…/og/stories-ru.jpg` → 200; есть только noindex. `stories-noindex.test.ts:97-101` проверяет для этих путей только заголовки, статус не проверяет.

## Проверено и корректно

- **Контракты.** Тела запросов совпадают с DTO при `forbidNonWhitelisted`, лишних полей нет: create/preview (`buildStoryPayload`), photo, approve, video/quote и video (`storyVideoRequest`), recording, references analyze/PATCH/plan/youtube, narrator-looks create/restyle/consent/apply/revert. Поля ответов `GET :id/video` совпадают с типом `View`.
- **Согласия.** Версии берутся с сервера: `voiceConsentVersion`, `recordingConsentVersion`, `consent.version` образа.
- **Ошибки.** Сообщение берётся из `error.message`. Для «нет ответа» свой текст без автоповтора. Ошибки микрофона по-русски.
- **Защита от повторов.** Двойной клик закрыт ref-замками (сказки, видео, референсы, образы, админка). Сборка видео — только по свежей смете с резервом на кнопке (ключ `bodyKey`). Черновик с репликой — только после свежего предпросмотра. Повторное создание того же ввода заблокировано. Опрос видео только читает (GET), автоповторов платных вызовов нет.
- **Запись вступления.** WAV PCM16 моно 22,05 кГц, автостоп на 20 с. Base64 ≤ 1 176 060 < лимита DTO 1 333 340. Уведомление об обрезке есть. При размонтировании микрофон освобождается без загрузки.
- **Медиа.** Аудио ≤ 3 МиБ и MP4 ≤ 3 МиБ — в пределах лимита ответа 4,5 МБ. Blob URL отзываются.
- **Вёрстка и a11y.** Экран сказок и блок образа на 320/360/1280 в обеих темах без горизонтального скролла. Поля подписаны (axe нашёл только контраст).
- **Админка.** Один `requestId` (UUID v4) на диалог. Проверка причины совпадает с серверной. Есть confirm с последствиями, отметки «нет списания», явный выбор резерва, `renderInputUrl`, `narrationKey`. Владельцы, тексты и медиа не показываются.
- **Лендинг.** 404 с noindex у корня поддомена, `/<locale>`, `/<locale>/stories` (поддомен и главный), `/stories-media/*`. Sitemap поддомена пустой, robots без Sitemap. В публичных страницах и sitemap ссылок на Story‑Tales нет (`LandingVisits` пропускает stories).
