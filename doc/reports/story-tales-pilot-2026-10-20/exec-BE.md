# ST3 — пакет BE (backend), 20.10.2026

## Решения пакета
- Р-ST3-BE-1. Цена кредита — самая низкая фактическая цена одного кредита среди всех пакетов и каналов (`creditPacks` × `estimateAmountMicroUsd`; по умолчанию 900★/20 = $0.675). Пакеты с 0 кредитов/0 цены игнорируются. f = 0.30 (числа комиссии Stars в коде/доках нет, ТЗ TMA: «ПРОВЕРИТЬ»), m = 0.5, floor $2.99 — на КАЖДЫЙ платный шаг (аудио и видео отдельно). По умолчанию шаг = 5 кредитов (usdEquivalent $3.38). Константы, не env.
- Р-ST3-BE-2. Бесплатная первая сказка участника = аудио + первая сборка видео этой же сказки; закрепляется при запуске аудио (`freeGiftId`/`freeGiftUsedAt`); возврат бесплатного шага возвращает право.
- Р-ST3-BE-3. Возврат кредитов — при любом окончательном FAILED, где пользователь ничего не получил: остановка видео до отправки сборщику (spend/plan/narrator), ошибка или брак результата сборщика, закрытие оператором `gifts/:id/close` и `renders/:id/close` (в ответе `creditsRefunded`). UNKNOWN держит резерв. Не возвращаются: удаление владельцем записи вступления (READY→FAILED по его действию), удаление сказки в UNKNOWN (оператор может вернуть вручную ADMIN_ADJUST).
- Р-ST3-BE-4. Правила Story нужны участнику/пользователю для любого POST Story (включая черновик, preview/quote, образ рассказчика) — 403 `STORY_TERMS_REQUIRED`; GET/DELETE доступны тому, у кого могут быть свои данные (отозванный участник, принявший прежнюю версию правил) — право на удаление. В `owner` не-владельцу всё 404.
- Р-ST3-BE-5. Отозванный участник не строит и в `public`; отзыв сразу снимает его публичные ссылки.
- Р-ST3-BE-6. Одна заявка на пользователя (unique); повтор возвращает её в любом статусе — отклонённый не подаёт заново.
- Р-ST3-BE-7. Admin approve/reject/revoke: тело `{reason?, requestId?}` необязательно (стандартная причина, новый UUID); повтор requestId — первый результат.
- Р-ST3-BE-8. Миграция очищает все прежние `shareHash` (ссылки до 17.10 не оживают при pilot).
- Р-ST3-BE-9. `retention.purgeAt` — дата по политике крона (30/180 дней) независимо от флагов `STORY_RETENTION_*`; если раньше кончается 90-дневная ссылка — её дата, `basis: published`. Крон опубликованные подарки на 90-й день не удаляет: кончается только ссылка (404 по запросу).
- Р-ST3-BE-10. 402 `{required, balance}` передаётся через `upstreamDetails` → `error.details` (common/filters не менялся; проверено тестом).
- Р-ST3-BE-11. Образ рассказчика (Gemini) и разборы референсов кредитами не тарифицируются (квоты, центы); платные шаги — только `:id/render` и `:id/video`.
- Р-ST3-BE-12. `slug` в capabilities — id редакции без `-<locale>-…` (`turnip-ushinsky`, `turnip-franko`): редакции разных авторов — разные сказки; добавлено `titles`.
- Р-ST3-BE-13. `STORY_TERMS_VERSION = 'story-rules-2026-10-20'` (LEGAL/FE должны использовать её; FE получает из `/access`).
- Р-ST3-BE-14. Баланс кредитов единый: бесплатные начисления (WELCOME/REFERRAL) тоже тратятся на Story.
- Р-ST3-BE-15. Отдельного крона-сверки возвратов нет: возврат сразу после перехода в FAILED; сбой возврата логируется, виден как RESERVED рядом с FAILED.

## Не сделано / риски
- Согласие рассказчика на ПУБЛИЧНОЕ распространение (ТЗ §11.1) не проверяется при публикации видео семейным голосом — нужен отдельный пункт согласия (LEGAL/следующий проход).
- Счётчики документов (миграции 146, таблицы 99, маршруты 698/104) — главный агент.

## Доработки по сообщению координатора
- `GET /story-gifts/access`: `maxMembers` в `pilot`.
- Строки повода UK/EN вычитаны (story-occasion.ts), тест.
- Р-ST3-BE-16 (§11.1): «не только Nova» = последняя одобренная READY-сборка с клоном (`userVoiceId`), своей записью вступления (`source: recorded`) или образом рассказчика (`narrator` в манифесте). Без `narratorPublicConsent: true` — 400 `STORY_NARRATOR_PUBLIC_CONSENT_REQUIRED`; факт и версия — `story_gifts.narratorPublicConsentAt/Version`, снимаются со ссылкой. Видео с таким рассказчиком, одобренное после выдачи ссылки без согласия, по ссылке не отдаётся. `narratorPublicConsentRequired` в `GET :id`.
- Р-ST3-BE-17 (§11.4): исходник голоса — только READY-клоны без персоны, через 7 дней по `updatedAt` (отдельной даты READY нет); Blob удаляется, `sampleUrl = ''`; FAILED не трогается (повтор после 400). Сценарий заявок approved/rejected — 90 дней после `decidedAt`. Журнал — DELETE старше 365 дней. Всё под `STORY_RETENTION_PURGE_ENABLED`, без него — счётчики.
- «Ріпка» Франко: approved, хеш в замороженной карте, стоит перед UK-адаптацией (первая для UA/uk); проверка классики в story-media.spec обобщена.

- Р-ST3-BE-19: «точно не списано» = TTS skipped или `Resemble 4xx`, либо ни одного платного вызова в полёте (флаг `uncertain`); всё остальное — UNKNOWN. UNKNOWN 14 дней → автовозврат из крона story-finalize (без флага retention).
- Р-ST3-BE-20: удаление сказки возвращает кредиты шагов SYNTHESIZING/UNKNOWN (аудио) и PREPARING/PENDING/UNKNOWN (сборки); READY/APPROVED — нет.

- Р-ST3-BE-22: повторный share с согласием при живой ссылке → 200 `{url: null, expiresAt, narratorConsentUpdated: true}` (токен не хранится, ссылку вернуть нельзя).
- Р-ST3-BE-23: отзыв участника в public не действует (обычный user) — по указанию координатора.
- Отзыв согласий снимает ссылку: удаление голоса (user-voices), записи (deleteRecording), отзыв согласия на образ (narrator-looks); страховка — `publicRelease` 404.

## Хвосты
- Р-ST3-BE-24 (правила 9.6): исходник голоса — 7 дней после последнего изменения для любого статуса (READY/TRAINING/FAILED), не персона, только у принявших правила Story; повтор клонирования после 400 требует сохранённую запись (`canRetryClone` проверяет `sampleUrl`).
- Р-ST3-BE-25: тексты согласий и `rights` каталога — по `Accept-Language` (ru/uk/en, иначе en; без заголовка — en, вызовы сервиса без локали — ru); язык текста согласия сохраняется (`voiceConsentLocale`, `consentLocale`).

- Р-ST3-BE-26 (S-14): статус списания CAPTURED при выполненном шаге; автовозврат — выборка только UNKNOWN-шагов (JOIN); свип captureDelivered в story-finalize + та же правка в миграции.
