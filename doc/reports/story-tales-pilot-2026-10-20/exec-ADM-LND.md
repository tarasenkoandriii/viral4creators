# ST3 — пакет ADM+LND (админка + лендинг), 20.10.2026

## Решения
- Р-ST3-ADM+LND-1. CTA пилота — существующий вход `t.me/<бот>/app?startapp=e_stories` (`lib/telegram-entry.ts`, зеркало `frontend/src/lib/start-param.ts`): голое `startapp=stories` TMA не разбирает. Новых построителей ссылок нет.
- Р-ST3-ADM+LND-2. Режим лендинга `STORY_TALES_LANDING` ортогонален `release.json` (`prep` остаётся: ни демо, ни формы, ни покупки на странице). Он решает 404/открыто, noindex, карту сайта и тексты доступа.
- Р-ST3-ADM+LND-3. Режим вклеивается при сборке (`next.config.js` → `env`) в страницу и middleware; неизвестное значение = `closed`. Проверено: сборка `pilot` под `next start` без env остаётся `pilot`.
- Р-ST3-ADM+LND-4. S3-7: страница перенесена в группу `app/(stories)/[locale]/stories` со своим layout (HtmlDocument без DictionaryProvider). URL прежние. Замер на сборке: строк словаря главной в HTML+RSC `/ru/stories` — 0 из 336 (у `/ru/greetings` — 298). Ключ бюджета — `/(stories)/[locale]/stories/page` (102.3/112 КБ).
- Р-ST3-ADM+LND-5. События: механизма событий с согласием у лендинга нет (`LandingVisits` — агрегатный счётчик без согласия, Story‑Tales исключена). События `story_*` не добавлялись.
- Р-ST3-ADM+LND-6. «Цена от» — только из API (`priceFromUsd`), в откате не показывается. В текстах нет цифр, валют и «бесплатно» (кроме «до 15 семей» в `access.pilot`). Бесплатная первая сказка упоминается только в админке.
- Р-ST3-ADM+LND-7. `pilot`/`public`: маршрутизация как до 17.10. Нелокализуемые пути хоста Story‑Tales (статика, `_next`, `/legal`, robots, sitemap, OG, медиа) идут дальше с заголовками Story‑Tales.
- Р-ST3-ADM+LND-8. `public`: нет `X-Robots-Tag`, meta `index, follow`, sitemap и `Sitemap:` в robots.txt поддомена, пункт «закрыто от индексации» скрыт; `Referrer-Policy: no-referrer` остаётся.
- Р-ST3-ADM+LND-9. Prettier в landing не запускался: у пакета нет конфига, соседний код им не отформатирован (дефолт переписал бы кавычки). Формат — руками в стиле файлов; admin — тоже руками.
- Р-ST3-ADM+LND-10. Админка шлёт необязательную причину и один `requestId` на диалог (повтор возвращает прежний результат). `apiDelete` принимает тело.
