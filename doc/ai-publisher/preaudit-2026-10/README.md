## Среда и отличия от production

- **Стенд:** песочница Linux (2 vCPU, 8 ГБ), PostgreSQL 16.13 на той же машине, Node 24.21.0, Chromium 141 headless. Базы пересоздавались из всех миграций.
- **Backend:** `node dist/main.js`, собранный из текущих исходников; `NODE_ENV=development`; fake-провайдер AI, внешней сети нет.
- **Сайт:** `publisher-site` — `next build` / `next start` за https-прокси на домене `pubsite.test` с самоподписанным сертификатом.
- **Отличия от production:**
  - нет Vercel: кронов платформы, HSTS платформы, перезаписи `X-Forwarded-For`, Blob-хранилища — копии хранились в локальном хранилище стенда (Р-PUB-Z2-22);
  - нет Supabase и пулера — один локальный Postgres; миграции `publisher_*` на production не выкачены, логин-роль `publisher_public` на production не создана;
  - нет реальной модели (ключа и утверждённого лимита нет) — AI проверен только как контур;
  - нет живого Telegram и пользователей: initData подписан тестовым ботом стенда;
  - время: календарь D42/D72/D90 — часами стенда (Р-PUB-Z2-21), 8 дней наблюдения и истечение согласования — сдвигом дат SQL-ом стенда; бизнес-данные SQL-ом не писались;
  - нет домена ai-publisher.org, реального телефона, Safari/WebKit;
  - протокол приёмки в qa-catalog на стенде засеян сидом (помеченная инфраструктура), живого прохождения 44 AT в qa-catalog нет.
- Внешние платежи, публикации у третьих лиц и сообщения заявителям не выполнялись.

## Что не входит в пакет

- Сырые логи, JSON прогонов, пробы и мутанты — в рабочем каталоге предаудита; md5 приведены в отчётах. Передаются внешнему исполнителю по запросу с ограниченным доступом (план §18).
- Закрытая техническая запись по D1-02 — не входит; в пакете описание обезличено.
- Закрытый дополнительный AI-набор `extra-set-v1.json` — не входит. Версия 1, 20 сценариев, sha256 `689c9d126ae511445a53487ca6fbdaec4f595962ff3d86ff75d34f4c9ee5ece8`, зафиксирован 2026-10-13T10:37:23Z до прогона. Входы сценариев из протокола исключены (план §9 D2).
- Секреты и контакты: синтетические контакты стенда в текстах заменены пометкой; значения секретов не приводятся.
