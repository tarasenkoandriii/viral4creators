# QA PDF font

Noto Sans Regular, copied from the repository's existing
`backend/src/assets/fonts/NotoSans-Regular.ttf` for local Cyrillic PDF generation.
Redistributed under SIL Open Font License 1.1 (`OFL.txt`, official
https://github.com/notofonts/noto-fonts/blob/main/LICENSE).
Full embedding is intentional: subset embedding produced missing Cyrillic glyphs
in the PDF renderer and was rejected during visual acceptance.
