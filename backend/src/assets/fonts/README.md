# Шрифт для text-card (ТЗ VEO-MODEL-VERSION-CHOICE-SPEC.md §20.3)

**Эта папка должна содержать два файла, которых здесь нет** — у среды
сборки этого ответа нет сетевого доступа, чтобы скачать бинарный файл
шрифта самостоятельно. `common/text-card-render.ts` ожидает их по
этим точным путям и упадёт с понятной ошибкой при старте, если их нет
(см. `readFontFile()` в том файле).

## Что скачать

1. https://fonts.google.com/noto/specimen/Noto+Sans → «Download family»
   (это официальный источник, `fonts.google.com`, не сторонний
   агрегатор).
2. В скачанном архиве — статические `.ttf`, не `NotoSans[wdth,wght].ttf`
   (вариативный шрифт, `satori` variable fonts не поддерживает
   надёжно, см. предупреждение ниже) — папка `static/`.
3. Скопировать сюда, переименовав ровно так:
   - `static/NotoSans-Regular.ttf` → `NotoSans-Regular.ttf`
   - `static/NotoSans-Bold.ttf` → `NotoSans-Bold.ttf`

## Почему именно эти два файла, не один

`satori` не умеет синтетически утолщать текст (`font-weight: bold` без
загруженного bold-начертания рендерится как обычный вес — молча, без
ошибки) — для CTA-текста, где визуальный вес важен для контраста на
фоне видео, нужен настоящий Bold-файл, не эмуляция.

## Проверено (не предположено)

Официальная страница fonts.google.com/noto/specimen/Noto+Sans
перечисляет украинский язык среди поддерживаемых, шрифт покрывает
блоки Cyrillic, Cyrillic Supplement и Cyrillic Extended-A — там же
специфично украинские глифы (Ґ/ґ, Є/є, І/і, Ї/ї). Сверено при
подготовке ТЗ §20.3, не при подготовке этого кода — если шрифт с тех
пор поменяли на Google Fonts, стоит перепроверить.

## Не проверено — сделать вручную перед тем, как полагаться на это

Сам рендеринг (`satori` → SVG → `@resvg/resvg-js` → PNG) не был
прогнан ни разу в этой среде (нет сети, чтобы поставить пакеты и
запустить). Первый реальный вызов после `npm install` — при
локальном/тестовом прогоне, не сразу на проде.
